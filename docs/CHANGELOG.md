# 更新日志

> 版本约定：同一天的修改直接追加到当天条目；一个功能块收尾或准备发版时，再统一升一个中版本（如 v0.5.x → v0.6.0）。

## 2026-09-03 v0.5.0
- 新增“更新日志”页面
- 品类标签详情补全：国家立法、法规草案、意见征询并入 A/B/C/G/H/I/J 分类；AI/Token 信用借贷类衍生争议归入 I
- UI 全面美化定稿：配色、圆角、阴影、间距、对齐、中文化
- 接口配置改为仅本次会话生效：key 不落盘、不回显，支持任意 OpenAI 兼容平台随时切换
- 服务端支持内网多人访问（0.0.0.0 监听 + 多线程），新增 `he-l_backup_20260903` 全量备份
- 自定义出题品类下拉与打标结果显示“字母 - 品类名”（如 B - 社会矛盾），便于手动指定品类
- 出题锚点规则重构：单轮整句与多轮首问统一为“对话起点必须独立定位事件”，禁止“那事/这事”类泛指；代码层复核覆盖单轮整句与多轮首问
